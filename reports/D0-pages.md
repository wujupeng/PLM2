# D0-04 前端页面静态分类与访问抽查

## 盘点范围

- 日期：2026-11-20
- 页面文件基数：`plm-frontend/src/pages/` 下 514 个 `.tsx` 文件。
- 路由基数：`src/router/index.tsx` 中 497 个 lazy-loaded 页面模块、499 条显式路由 path；485 个路由元素使用 `withPermission`。
- 分类原则：只检查源码中的 service 引用、lazy route 引用与组件类型；**引用 API service 不代表运行时成功、页面数据真实或权限正确**。逐文件分类见 [D0-04 页面清单 CSV](./D0-pages.csv)。
- 动态抽查：使用隔离浏览器上下文访问本机 `127.0.0.1:3000/login` 和受保护路径 `/bom`。登录页正常渲染；未认证访问 `/bom` 被重定向到 `/login`。没有提交凭据、没有写入业务数据。
- 测试限制：Gateway `127.0.0.1:8080` 无响应，且本轮没有使用有效测试账号；无法通过登录对 514 个页面逐页分类数据态、403、白屏或截图。

## 分类结果

| 类别 | 数量 | 证据与限制 |
|---|---:|---|
| 源码引用 API service 的路由模块 | 491 | 页面模块导入前端 service；运行时请求是否成功、数据是否来自真实业务库尚未验证。 |
| 路由壳页/基础页（无业务 service 引用） | 6 | 登录、工作台、制造协同提示页、系统子路由容器、移动端“更多”、404。工作台包含静态 0 值/阶段示例；制造协同页为提示内容，不能计为已实现业务数据页。 |
| 未被 router lazy-import 的 TSX 辅助文件 | 17 | 共享组件/对话框/页内辅助文件，不是独立可导航页面，避免按页面误报。 |
| 路由访问实际抽查 | 1 个受保护路由 | `/bom` 在无会话上下文下重定向至 `/login`；只证明认证守卫工作，不代表账号权限矩阵/403 正确。 |
| 真实数据页面已通过动态验证 | 0 | Gateway 不可用，无法以登录态对 API/UI 数据逐页验证。 |
| 动态确认白屏 | 0 | 没有对所有路由执行已授权 UI 访问；不能将静态扫描未发现等同于不存在白屏。 |
| 动态确认 403/无权限页 | 0 | 缺少有效的有权限/无权限测试身份和可用 Gateway。 |

截图证据保存在 [D0-04 截图目录](./evidence/D0-04/)：空会话登录页和未认证访问受保护路由后的登录页。截图不含已登录业务数据。

## 发现与阻塞

1. 514 个 TSX 文件中，只有 497 个被 router 以 lazy module 引用；其余 17 个是辅助 UI 文件，不应作为可独立访问页面统计。
2. 491 个路由模块源码引用 service，但实际数据源、字段契约、错误提示、权限及列表 CRUD 均需登录态动态测试。
3. Dashboard 静态显示物料/BOM/变更/文档数量为 0，并显示固定阶段文本；Manufacturing 页面显示阶段说明和返回按钮。两者当前是静态壳/提示页，不构成业务模块实际数据联通证据。
4. 所有受保护业务路由需要登录，485 个路由额外包装了 `withPermission`。由于 Gateway 不可用，无法登录或遍历不同角色，导致“真实数据/无权限/白屏”验收整体受阻。

## D0-04 结论

页面源码清点和结构分类已完成；少量路由的匿名态访问已抽查。按 WBS 要求的真实数据页、静态壳页、白屏页、无权限页**逐页运行分类尚未完成**，D0-04 记为**部分完成/受阻**。解除阻塞条件：Gateway 与隔离测试数据可用、至少具备有权限与无权限的测试角色，然后运行逐页 Playwright、保存登录态截图与错误/网络证据。
